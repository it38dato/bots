# Telegram-бот Переводчик (translatorTelegaBot)

Удобный Telegram-бот для автоматического перевода текста и определения языков. Бот поддерживает перевод на английский и грузинский языки, умеет распознавать исходный язык ввода и оптимизирован для работы в среде Linux как системная служба.

## ✨ Функции

* **Перевод текста:** перевод слов и фраз на английский и грузинский языки.
* **Определение языка:** автоматическое распознавание языка вводимого текста.
* **Автоматизация:** готовые скрипты для развертывания окружения и управления службой в Linux.

---

## 📁 Структура проекта

* `main.py` — основной скрипт для запуска бота.
* `.env` — файл для хранения конфиденциальных данных и настроек БД.
* `scripts/` — вспомогательные скрипты для настройки и автоматизации:
  * `fileExecute.sh` — делает файлы автоматизации исполняемыми.
  * `pythonCheck.*` — проверка наличия Python и Pip (для Windows и Linux).
  * `git*.sh` — скрипты для автоматизации работы с GitHub (инициализация, поиск изменений, коммиты).
  * `dbSet/dbDictionary.png` — схема структуры таблиц базы данных.
  * `envSet/config.json` — конфигурационный файл для создания окружения.
  * `envSet/installEnv.sh` — скрипт автоматического развертывания проекта и зависимостей.
  * `systemdSet/dato38itbot.service` — юнит-файл для systemd (автозапуск бота в Linux).
  * `systemdSet/startService.sh` / `stopService.sh` — скрипты управления службой бота.
  * `testScripts/` — тесты (`test*.py`) и описание шагов тестирования (`steps.tx`).

## ⚙️ Настройка перед запуском

### 1. Настройка окружения (`scripts/envSet/config.json`)
Перед развертыванием проверьте и отредактируйте конфигурационный файл. Если оставить пути пустыми, проект создастся в домашней директории пользователя:
* `project_path` — путь для сохранения проекта.
* `project_name` — имя папки проекта (по умолчанию `translatorBot`).
* `env_name` — имя виртуального окружения (по умолчанию `envTranslatorBot`).
* `libraries` — список зависимостей.
* `proxy` — заполните, если запуск происходит в корпоративной сети через прокси.

### 2. Переменные окружения (`.env`)
Создайте файл `.env` в корне проекта и укажите ваши данные:
```env
TOKEN='ВАШ_ТОКЕН_ТЕЛЕГРАМ_БОТА'
DB_URL='postgres://ПОЛЬЗОВАТЕЛЬ_БД:ПАРОЛЬ_БД@ХОСТ_БД:5432/НАЗВАНИЕ_БД'
ADMIN_ID=ВАШ_ТЕЛЕГРАМ_ID
```

### 3. Автоматическое развертывание
Запустите скрипт для подготовки директорий и установки всех зависимостей:
```bash
chmod +x scripts/envSet/installEnv.sh
./scripts/envSet/installEnv.sh
```

## 🚀 Запуск проекта

Перед ручным запуском обязательно перенесите настроенные файлы `.env` и `main.py` в созданную целевую папку проекта (например, в `/home/dato/translatorBot/`).

### Ручной запуск:
```bash
# Активация виртуального окружения
source /home/dato/envTranslatorBot/bin/activate

# Запуск бота
python3 /home/dato/translatorBot/main.py
```

### Демонизация (запуск как службы в Linux):
1. Отредактируйте файл `scripts/systemdSet/dato38itbot.service`, указав актуальные пути к вашему окружению и скрипту.
2. Скопируйте юнит-файл в системную директорию systemd.
3. Используйте встроенные скрипты для управления:
   * Запуск службы: `./scripts/systemdSet/startService.sh`
   * Остановка службы: `./scripts/systemdSet/stopService.sh`
