Телеграм-бот Переводчик.

Функции:
- перевод слов и фраз на разные языки (Английский и Грузинский).
- Определение языка текста.

Структура проета:
- main.py - основной скрипт для запуска проекта
- .env - файл для хранения логинов и тонека бота в формате TOKEN='ТОКЕН_БОТА' DB_URL='postgres://ПОЛЬЗОВАТЕЛЬ_БД:ПАРОЛЬ_БД@ХОСТ_БД:5432/НАЗВАНИЕ_БД' ADMIN_ID=ID_БОТА. Необходимо ввести свои параметры
- scripts/fileExecute.sh - скрипт делает файл иссполняемым для запуска скриптов.
- scripts/pythonCheck.* - скрипты проверяет установку Python и Pip для Window и Linux.
- scripts/git*.sh - скрипты Добавляют новый проект в гитхаб, находят изменения в проект и добавляют новые изменения в гитхаб
- scripts/dbSet/dbDictionary.png - структура таблицы БД.
- scripts/envSet/config.json - настройка проекта. project_path - путь куда сохранить проект. Если оставить пустым - проект, по умолчанию, сохранит в  папку пользователя. project_name - навазние проекта. Можно свое название. По умолчанию, это будет translatorBot. env_name - название переменной окружения. Можно свое название. По умолчанию, это будет envTranslatorBot. libraries - бибилиотеки, от которых зависит проект. proxy - необходим если вы запускаете скрипт в коммерческой сети, где используется прокси. По умолчанию он будет пустым.
- scripts/envSet/installEnv.sh - Готовит проект с директорией и настраивает зависимости. Перед запуском необходимо проверить файл scripts/envSet/config.json
- scripts/systemdSet/dato38itbot.service - конфигурационный файл службы (юнит-файл) для системы инициализации systemd. нужен для автоматизации работы Telegram-бота в Linux. В файле необходимо добавить свои параметры
- scripts/systemdSet/startService.sh - Скрипт для запуска службы dato38itbot.service.
- scripts/systemdSet/stopService.sh - Скрипт для остановки службы dato38itbot.service.
- scripts/testScripts/test*.py - тестовые скрипты для запуска проекта. Для запуска скрипта необходимо перенести скрипты в папку с настроеннным проектом.
- scripts/testScripts/steps.tx - описание скриптов test*.py

Перед запуском скрипта необходимо перенести файлы .env и main.py в папку с настроеннным проектом.
Для запуска скрипта необходимо запустить команды:
source /home/dato/envTranslatorBot/bin/activate
python3 /home/dato/translatorBot/main.py
